# @deepseek-ai/dsh-client-ui-workspace-files

[English](README.md) | 中文

工作区文件浏览插件。`FileTree` 填充侧边栏外壳的 `sidebar.files` 插槽——以懒加载的文件/目录树展示当前会话的规范化工作目录；`FileViewer` 填充布局的 `workspace.fileViewer` 插槽，即文件模式下中间列的内容。两个注册共享同一个打开页签 store 句柄，因此树的打开手势与查看器的页签栏驱动同一份状态。

点击文件（树行）会把文件加入打开页签列表并激活，然后通过 `ctx.layout.openFileMode()` 切换到文件模式：查看器占据中间列，聊天对话框停靠到右侧轨道成为可拖动面板。查看器的页签栏支持同时打开多个文件——点击页签切换激活，×（或页签右键菜单：关闭／关闭其他／关闭全部）关闭；关闭最后一个页签时调用 `ctx.layout.closeFileMode()`，聊天返回中间列。目录按需展开——每展开一层产生一次 `host.listDirectory` 调用并本地缓存；隐藏（点前缀）条目与目录选择器的默认行为一致，被过滤掉。

文件行与页签携带**按类型区分的徽标**（TS／JS、`{ }`、`M↓`、`#`、`<>`、`>_` 等，按扩展名推导），不再统一使用代码图标。代码主体**按语言语法高亮**——经 ui-primitives 高亮器（`highlightLines`，语法按需懒加载——首次渲染回退为纯文本，语法注册后自动重新高亮）——并带可选的**行号栏**；主体右键菜单可开关行号与高亮。**代码字体大小**是持久化用户设置：包 node 半侧注册 `workspace-files` 设置命名空间（schema 默认 12 px，范围 10–24），浏览器半侧经 `ctx.settingsScope` 绑定并镜像进共享 store，通用设置页的**文件字体大小**行用有界 ± 步进器调整。

可读文本页签**可编辑**：编辑开关把高亮主体切换为纯文本编辑器，编辑内容经 `host.writeFile` 在 1 秒防抖后**自动保存**（切换或关闭页签时立即刷新）。脏页签带圆点标记；保存失败显示带"重试"的错误条并保留草稿。Host 侧原子写入（临时文件 + 重命名，复用 atomic-write 工具），其余失败报 `file-write-failed`。文件内容经 `host.readFile` 整体读取，受 Host 字节上限约束，每个页签只读取一次（切换页签不重读）；过大、非文本或不可读的文件渲染本地化的错误文案而非内容，且不可编辑。

侧边栏外壳拥有会话/文件视图切换（`sidebar.files` 由它声明）；本包仅通过 `slots.inject()` 按声明生命周期注册进该插槽。

## Model Experience

无，文件浏览器属于浏览器界面；不会向模型请求发送任何内容。

#### KV Cache effect

无；本包既不组装也不发送 provider 请求。

## Known Limitations and Deferred Work

- **编辑是纯文本区域，编辑时不提供就地高亮或行号**——高亮、带行号的主体只读；进入编辑后切换为等宽 textarea。更完善的编辑器（CodeMirror／Monaco 一类）延后。
- **无并发编辑保护**——查看器整文件自动保存；读取与保存之间发生的外部修改会被覆盖（原子写保证不产生半写文件，但不保证不丢更新）。
- **二进制与超大文件不可编辑**——读取失败的内容（过大、非文本、不可读）渲染错误文案且编辑开关禁用。
- **树以当前会话的工作目录为根**——切换会话会重新生根；文件视图内暂无工作区选择器。
- **无刷新或实时监听**——树按需拉取，页签内容按查看器会话缓存；外部文件变更不会被推送或重读。
- **无行虚拟化**——接近读取上限（1 MiB）的文件每行一个 DOM 行，超大文件可能较慢。
- **隐藏条目始终隐藏**——与目录选择器不同，文件树暂时没有显示隐藏文件的开关。
- **字体大小是单一全局值**——暂无按文件或按会话的字体大小；通用设置步进器将其限制在 10–24 px。
