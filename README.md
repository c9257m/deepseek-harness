# DeepSeek Harness

[English](README.en.md) | 中文

DeepSeek Harness（`dsh`）是由 [DeepSeek AI](https://deepseek.com) 开发的开源 agent harness（智能体框架）。

它采用**一切皆插件**的架构，并由 [Cordis](https://github.com/cordiverse/cordis) 驱动，其设计参见论文 [_A Programming Paradigm for Spatiotemporal Composability_](https://github.com/cordiverse/paper)。

## 开发者预览

DeepSeek Harness 目前处于 _开发者预览_ 阶段，正在快速迭代。**未来将出现破坏兼容性的变更。**

## 运行

### 通过 `npm` 运行

安装 `Node.js`，然后运行：

```sh
npx @deepseek-ai/dsh web
```

该命令会启动 Web UI，默认地址为 `http://127.0.0.1:3080`。详见 [Web UI 指南](docs/user/guide/index.md)。

### 从源码运行

如需从仓库源码运行：

```sh
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web
```

## 桌面应用

Windows 桌面端提供免命令行的安装与启动途径：安装包自带独立的 Node.js 运行时，安装后双击桌面快捷方式即可打开 Harness，无需预先安装 Node.js，也无需打开终端。

- NSIS 安装包由 `pnpm desktop:dist` 生成到 `apps/desktop/dist/`，支持选择安装目录并创建桌面快捷方式。
- 所有用户数据——模型凭据、设置、会话与存储——都存放在 `$DSH_HOME`（默认 `~/.dsh`），位于安装目录之外；安装包只包含应用本体，可以放心分发。
- 源码开发时用 `pnpm desktop:dev` 启动桌面外壳（端口 `32080`），`pnpm desktop:pack` 生成免安装的解包目录以便快速迭代。

```sh
pnpm desktop:dev
pnpm desktop:pack
pnpm desktop:dist
```

详见 [apps/desktop/README.md](apps/desktop/README.md)。
